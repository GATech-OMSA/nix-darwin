# Nix Darwin Configuration

Declarative macOS system configuration using Nix + Home Manager.

---

## What This Is

A **complete system configuration** for macOS that:

- Manages system packages declaratively (no manual installs)
- Configures all applications (Git, VS Code, Shell, etc.)
- Handles secrets securely (SOPS + age encryption)
- Works across multiple machines (personal + work)
- Provides one-command system reproduction
- Enables instant rollbacks if something breaks

**One command rebuilds your entire system**: `nix-rebuild && exec zsh`

## Structure

```
nix-darwin/
├── flake.nix                 # Entry point (static machine registry)
├── config/                   # Machine and user configuration (gitignored)
│   ├── machine-config.nix    # machineId + profileName
│   └── user-config.nix       # username + email
├── nix-config/               # All Nix configuration files
│   ├── hosts/                # Machine-specific configs + secrets
│   │   ├── _template/        # Template for new machines
│   │   ├── macbook-pro-m1-personal/   # Personal machine
│   │   └── macbook-pro-m3-work/       # Work machine
│   ├── home/                 # Home Manager configurations
│   │   ├── _profiles/        # Profile system (personal/work/minimal)
│   │   │   ├── _template/    # Shared programs and shell configs
│   │   │   ├── personal/     # Personal profile behavior
│   │   │   ├── work/         # Work profile behavior
│   │   │   └── minimal/      # Bare-bones troubleshooting
│   │   └── _template/        # Base template configurations
│   ├── modules/              # System packages + settings (darwin/shared)
│   ├── lib/                  # 30+ helper functions
│   └── overlays/             # Package customizations
├── scripts/                  # Utility scripts
│   ├── setup/                # preflight.sh, bootstrap.sh, configure.sh, activate.sh
│   ├── secrets/              # deploy, edit, view, backup, rescan, status, audit
│   └── maintenance/          # System maintenance
├── cache/                    # Pre-built binaries (sops-install-secrets)
├── docs/                     # User-facing documentation
└── workspace/                # Per-machine workspace (gitignored)
```

## Installation

### Quick Start

```bash
# 1. Clone
git clone YOUR_REPO_URL ~/nix-darwin && cd ~/nix-darwin

# 2. Check what's needed
./scripts/setup/preflight.sh

# 3. Install prerequisites (Nix, sops, age)
./scripts/setup/bootstrap.sh

# 4. Configure (interactive — creates config files + host directory)
./scripts/setup/configure.sh

# 5. Build and activate
./scripts/setup/activate.sh

# 6. Deploy secrets
secrets-deploy

# 7. New shell
exec zsh
```

### Set Up Secrets

```bash
# Age key is generated by bootstrap.sh at:
~/.config/sops/age/keys.txt

# Edit encrypted secrets
secrets-edit

# Deploy to target paths (no rebuild needed)
secrets-deploy

# Re-source in current shell
secrets-reload
```

See [docs/aws-and-secrets-workflow.md](docs/aws-and-secrets-workflow.md) for the full reference.

### First Build

```bash
# The flake target uses your machineId from config/machine-config.nix
sudo nix run nix-darwin -- switch --flake .#macbook-pro-m1-personal   # Personal
sudo nix run nix-darwin -- switch --flake .#macbook-pro-m3-work      # Work
```

## Common Commands

### Building

```bash
nix-rebuild            # Rebuild with pre-flight checks
just build             # Test build without switching
nix-rollback           # Rollback to previous generation
```

### Secrets

```bash
secrets-edit           # Edit encrypted secrets.yaml
secrets-deploy         # Decrypt + deploy (no rebuild needed)
secrets-reload         # Re-source in current shell
secrets-status         # Check status of everything
secrets-rescan         # Discover unmanaged secrets
```

### AWS

```bash
awslogin <proj> <env> [role]   # SSO login
awsuse <proj> <env> [role]     # Switch profile
awswho                         # Show current identity
awslist                        # List all accounts
```

### Adding Packages

```bash
# System packages:
nano ~/nix-darwin/nix-config/modules/darwin/packages.nix
nix-rebuild && exec zsh
```

## Multi-Machine Setup

Profile is set in `config/machine-config.nix`:

```nix
{
  machineId = "macbook-pro-m3-work";
  profileName = "work";    # "personal" | "work" | "minimal"
  system = "aarch64-darwin";
}
```

The flake exports all machines from a static registry — both can be
build-tested from either machine:

```bash
nix build .#darwinConfigurations.macbook-pro-m1-personal.system --dry-run
nix build .#darwinConfigurations.macbook-pro-m3-work.system --dry-run
```

## Troubleshooting

```bash
# Command not found after install
exec zsh

# Build fails
darwin-rebuild switch --flake . --show-trace
nix-rollback   # if needed

# Secrets not loading
secrets-status     # Check age key, encryption, deployed files
secrets-deploy     # Re-deploy
secrets-reload     # Re-source

# Wrong profile
echo $ACTIVE_PROFILE
nano config/machine-config.nix   # Change profileName
nix-rebuild && exec zsh

# Age key location
ls ~/.config/sops/age/keys.txt
```
